# In-Browser Cryptography Playground

This project is an interactive, in-browser cryptography playground that allows users to experiment with classic and modern cryptography basics. It's designed for students, enthusiasts, and educators who want to learn and teach cryptography in a hands-on way.

## Features

*   **Classical Ciphers**: Caesar and Vigenère ciphers with real-time encryption and decryption.
*   **Hashing Tool**: SHA-256 and MD5 hashing with a real-time avalanche effect visualization.
*   **Symmetric Encryption**: AES encryption and decryption with session-based key generation.
*   **Brute Force Tool**: A brute-force tool to crack the Caesar cipher, with a progress bar and confetti on success.
*   **Modern UI**: A clean and intuitive user interface with a tab-based layout, theme switcher, and smooth animations.
*   **Explanatory Guidance**: Tooltips and an "About" section with a disclaimer.
*   **Accessibility**: ARIA attributes and keyboard navigation support.

## Setup

To run the project locally, simply open the `index.html` file in your web browser. No server is required.

## Technical Highlights

*   **Client-Side Cryptography**: All cryptographic operations are performed in the browser using the WebCrypto API. No data is sent to a server.
*   **Real-Time Updates**: The UI updates in real-time as you type, providing instant feedback.
*   **Educational Focus**: The project is designed to be an educational tool, with clear explanations and visualizations.

## Security Disclaimer

This project is for educational purposes only. The cryptographic functions provided here are not guaranteed to be secure. Do not use them to protect sensitive data.
